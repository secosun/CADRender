# CADRender: Distributed AI-Driven 3D SaaS Platform

`CADRender` 是一个工业级的分布式 3D 渲染云平台架构，旨在通过 AI 意图解析屏蔽复杂的专业 3D 操作，实现从「自然语言描述」到「高品质电商/工业渲染图」的自动化生产流水线。

## 🏗️ 架构分层 (Orchestration)

项目采用 **中台调度 + 边缘执行** 的分布式设计，通过 Git Submodules 进行集成管理：

1.  **[Blenderserver](./blenderserver) (The Orchestrator)**
    *   **角色**：SaaS 业务中台。
    *   **核心能力**：LLM 意图解析 (Natural Language -> Intent JSON)、多租户任务队列管理、异步消息分发。
    *   **技术栈**：Python, REST API, Task Broker.

2.  **[BlenderWorker](./blenderworker) (The Execution Kernel)**
    *   **角色**：分布式渲染执行单元。
    *   **核心能力**：
        *   **几何治理**：自动处理 CAD 导入瑕疵（Weighted Normals, Smooth Shading）。
        *   **智能对焦**：基于体积权重的重心 (Center of Mass) 算法实现专业摄影级构图。
        *   **自愈部署**：启动时自动检测并静默安装 Blender 4.5 环境，维护 TCP 持久连接。
    *   **技术栈**：Blender Python (bpy), JSON-RPC over TCP.

## 🚀 核心技术优势

*   **智能回退机制 (Intelligent Fallback)**：当用户需求模糊时，系统能根据物体的长宽比和几何密度，自动推算最优光照强度与相机距离。
*   **双阶段工作流 (Feedback Loop)**：支持 EEVEE 快速预览与 Cycles 生产级高清渲染的无缝切换，显著降低云端计算成本。
*   **存储抽象 (Cloud-Agnostic)**：使用 `cloud://` URI 协议，支持跨节点的分布式对象存储集成。
*   **高并发支持**：Worker 支持单卡多实例引擎池管理，最大化利用云端 GPU 算力。
